# Créditos das imagens

As ilustrações 3D desta pasta (`*.webp`) são do **Microsoft Fluent Emoji**
(https://github.com/microsoft/fluentui-emoji), distribuídas pelo pacote npm
`@lobehub/fluent-emoji-3d@1.1.0`. Licença **MIT**: podem ser usadas, copiadas e
modificadas livremente, inclusive em projetos acadêmicos e comerciais.
